# Noor-ul-Quran data

Versioned resource downloads for the Noor-ul-Quran Android app.

## Bengali Tafsir Ibn Kathir

- Original work: Tafsir Ibn Kathir.
- Language: Bengali.
- Digital source: [Quranic Universal Library (QUL) by Tarteel, resource 31](https://qul.tarteel.ai/resources/tafsir/31).
- Export: the original QUL JSON ZIP, preserved without text changes.
- Coverage: 6,236 ayahs mapped to 1,914 commentary passages; shared ayah references are preserved.

Download the ZIP from the repository's Releases. The Android app pins a versioned asset URL and verifies the archive's SHA-256 before installation.

The tafsir text retains its original rights and attribution. This repository does not assign a blanket open-source licence to that text.
